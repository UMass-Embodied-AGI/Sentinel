$TaskDescription$

Now the agent just received a new information from teammates. Your task is to **extract all available ETA information** — both from the conversation history (other agents’ reported ETAs), and **extract all available agent poses** and **sentinel poses** from the conversation history.

—

**Input:**

- Agent’s Name: $SelfName$

**Agent List:**  
$AgentList$

- Available Places:
$Places$

- Conversation History (may contain other agent’s ETAs to specific places or their current poses):
$ConversationHistory$

—

**Output Format:**

Return a JSON object structured as:

```json
{
    "ETA Map": {
        "<Place Name>": {
            "Agent1": "00:00:15",
            "Agent2": "Impossible",
            ...
        },
        "<Another Place>": {
            "Agent3": "01:14:30",
            ...
        }
    },
    "Agent Poses": {
        "Agent1": [0.0, 80.0],
        ...
    }
    "Sentinel Poses": [
        [-55.0, 176.0, 108.55],
        ...
    ]
}
```

Use exact place names from $Places, enclosed in <> as keys.
For each place, include a sub-object mapping agent names → ETA in "HH:MM:SS" format.
For each agent poses, include the xy coordinate enclosed in [].
Include:
Self’s ETAs from App Message.
Other agents’ ETAs mentioned in Conversation History (e.g., “I can get to <Park> in 10 min”).
Other agents' poses mentioned in Conversation History (e.g., "I'm currently at [-133.75, 62.37]")
sentinels' poses mentioned in Conversation History (e.g., "I see a sentinel at [-133.75, 62.37, 108.55]")
If an agent mentions multiple ETAs, use the most recent one.
If no ETA is available for a place, omit that place entirely.
If no ETAs found at all, return an empty object: {}

Parsing Rules:

Extract only numeric ETAs explicitly tied to a place and an agent, unless an agent cannot go to that place, in which case you should use "Impossible".
Ignore vague statements like “soon” or “about 10 minutes” unless a number is clearly stated.
Match agent names exactly as they appear in history or as SelfName.

This output will be used to compute optimal meeting locations. Be accurate and conservative — only extract clear, explicit ETAs and poses.

Please generate your response now.
